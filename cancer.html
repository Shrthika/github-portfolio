Colorectal Cancer Detection using STARC-9

A medical image analysis project focused on the early detection of colorectal cancer using a custom hybrid deep learning model. The project leverages the recently released STARC-9 histopathology dataset to identify Stage 0 and Stage 1 cancer cases and improve diagnostic accuracy through advanced deep learning techniques.

Key Features

  • Early-Stage Cancer Detection
  • Hybrid Deep Learning Architecture
  • Medical Image Classification
  • STARC-9 Dataset Integration
  • Performance Comparison with Baseline Models
  • Focus on Stage 0 & Stage 1 Detection

Technology Stack

  • Python
  • Deep Learning
  • TensorFlow / PyTorch
  • OpenCV
  • Medical Image Analysis
  • STARC-9 Dataset
